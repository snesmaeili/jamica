On CPU, `chunk_size="auto"` now sizes the E-step time-chunk to keep its `(n_components, n_mix_comps, chunk)` hot buffer resident in last-level cache instead of filling system RAM. The AMICA E-step is memory-bandwidth-bound on CPU, so a cache-resident chunk runs about 2x faster than full-batch (measured ~1.9x end-to-end on 8-core x86, jax CPU) while using a fraction of the peak memory. The converged fixed point is unchanged (log-likelihood agrees to ~1e-14). The GPU auto path is unaffected: it still sizes against the VRAM budget and returns full-batch whenever the data fits.
