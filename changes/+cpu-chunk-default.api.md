The default `AmicaConfig.chunk_size` is now `"auto"` (previously `None`, i.e. full-batch). CPU fits are now cache-chunked by default and are substantially faster with lower peak memory. This reassociates the time-axis reductions relative to full-batch — an algebraic identity (same fixed point, log-likelihood agreement ~1e-14), but not a byte-identical trace. To reproduce the exact pre-0.x full-batch reduction order, set `chunk_size=None` explicitly.
