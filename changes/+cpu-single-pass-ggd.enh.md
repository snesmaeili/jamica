The single-model E-step accumulator (`_chunk_stats_one_component`) no longer re-evaluates the generalized-Gaussian shape power multiple times per mixture. It computes `log|y|` once and derives `|y|^(rho-1)` with a single exponential and `|y|^rho` as an exact product, and reuses the Newton `kappa` sum for `mu_denom_gt2` (they are algebraically identical). This removes all `power` calls from the compiled E-step (optimized HLO: `power` 6 → 0) and is ~1.3x faster on the full-batch CPU kernel; combined with cache-aware chunking the default CPU path is ~2.1x faster than before. The converged fixed point is unchanged (log-likelihood identical to ~1e-14).
