The chunked E-step no longer recomputes `log|det W|` (a QR factorization) inside every time-chunk. Since W is fixed across the chunks of one iteration, `_amica_step_chunked` now computes it once and passes it into `compute_chunk_stats`. With the cache-sized default chunking this removes O(n_samples / chunk) redundant QRs per iteration; the effect grows with channel count and chunk count (~4% faster E-step at 128 components / 64 chunks). Numerically identical — the same scalar is added to each per-sample log-likelihood as before.
